# 🎫 Support Ticket Classification

An end-to-end Machine Learning project that analyzes customer support tickets and predicts their **ticket type** and **priority level** from the provided subject and description.

## 🚀 Features
- **Ticket Type Prediction:** Classifies customer support requests into categories.
- **Priority Prediction:** Predicts the priority level of a support ticket.
- **Text Preprocessing:** Cleans and prepares text for machine learning.
- **Machine Learning Models:** Uses TF-IDF and Scikit-learn classifiers.
- **Interactive Web App:** Provides a simple interface built with Streamlit.

## 🛠️ Tech Stack
- Python
- Pandas
- Scikit-learn
- Joblib
- Streamlit
- Natural Language Processing (NLP)

## ⚙️ How to Run

1. Clone this repository.
2. Install the required dependencies:
   `pip install streamlit scikit-learn pandas joblib`
3. Ensure both trained model files are available in the expected model directory.
4. Start the application:
   `python -m streamlit run app.py`

## 🎯 Project Objective

The goal is to explore how machine learning and natural language processing can help automate the initial classification of customer support requests.

## ⚠️ Limitations

The current models have limited predictive accuracy and are intended for learning and demonstration purposes. Predictions should be reviewed manually before practical use.
